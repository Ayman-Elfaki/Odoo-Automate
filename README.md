# Odoo Automate

This Chrome extension streamlines your point-of-sale workflow by automating repetitive actions such as customer (latch) selection and invoice creation. 
It is designed for businesses using web-based POS systems and looking to reduce manual clicks, speed up checkout, and improve accuracy.

---

## **Features**
- **Automatic Customer Selection (Latch Automation)**  
  Detects and selects the correct customer on supported POS pages.

- **Auto-Invoice Generation**  
  Automatically triggers invoice creation once the customer is selected.

- **Lightweight & Efficient**  
  Runs quietly in the background with minimal configuration.

- **Domain-Restricted Operation**  
  Works only on the POS domains you explicitly allow.

---

## **Permissions**
The extension uses the following Chrome permissions:

- **tabs** - To detect the active POS tab and ensure automation runs only where intended.  
- **webNavigation** - To trigger automation when the POS page loads or changes state.  
- **host permissions** - Limited to the POS domain(s) you configure, allowing the extension to interact with page elements.

---

## **Installation**
1. Install the extension from the Chrome Web Store.  
2. Grant permissions when prompted.  
3. Configure your POS domain(s) in the extension settings.  
4. Reload your POS page — automation will run automatically.
